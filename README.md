# Cabecudo

Made with [my-game-engine](https://github.com/leandrocoder/my-game-engine).

This folder is the engine project: open it in the editor with *Project → Open project folder…* and press Play.

- `Build/index.html`: the exported game (the `export_game` MCP tool, or *Export* in the editor). The editor ignores `Build/`, hidden folders like `.git` and files that are not assets, like this README.
